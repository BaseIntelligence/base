## API / behavior surface
- RegistrationStub: unregistered / set_uid / clear (local only)
- epoch_from_block / epoch_from_chain: epoch_index = current_block / epoch_length
- SyncChain: Mutex wrapper so FakeChain (!Sync) is Send+Sync for Arc health checks
- CoordinationClient: allowlisted GET only; MASTER_ONLY_PATHS refused before network

  - master-only: /v1/weights/raw /v1/admin/seal /v1/admin/backends /v1/master/status /challenge/*
- tick(): GET /v1/weights/latest when gateway set; no-op without gateway
- spawn_validator: telemetry router /healthz /readyz /metrics + graceful shutdown watch
- Injectable ReadyCheck for chain + db (db_ready_ok / db_ready_from_fn)
